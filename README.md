# humanizer

Скилл для Claude.

Очеловечивает тексты на русском: убирает канцелярит, AI-обороты и структурный слоп (38 паттернов), сохраняя смысл и добавляя голос там, где он уместен. Ничего не выдумывает. Есть режим детекта — находит и цитирует паттерны без переписывания.

## Когда использовать

- Текст звучит как нейросеть
- Нужно убрать канцелярит
- Проверить черновик на AI-паттерны

Не подходит для добавления характера и позиции (punker) и написания текста с нуля (author-in-residence).

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/humanizer.git ~/.claude/skills/humanizer
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `humanizer`.
